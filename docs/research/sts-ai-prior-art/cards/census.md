# Census: StS AI projects the angle scouts missed

One general-purpose agent (2026-11-15) searched slaythespire.dev/projects, GitHub (gh search repos) and the web for StS1 and StS2 AI projects not in the angle cards, and opened each README. "Sees RNG" says whether its combat search reads the game's hidden random state (draw order, enemy rolls). Results are as each README reports them; silverbot, Spire Mentor (via the sts2ai paper) and the clairvoyance notes were re-checked by hand (see the report).

## Notes from the census agent

I found 35 projects the prior survey missed. Nine report a strength number. The strongest:

1. silverbot / heart1 (daniel-ziegler's sts_lightspeed fork). Ironclad heart kill at A20: 18.6% in simulation, 1000 games. At A0: about 83%. Its search does not see the RNG. typed-decision-slay-the-spire measured A0 on its own: 165 of 200.
2. Spire Mentor (tfriedel), StS2. In its own simulator: Ironclad 96% at A0 and 27-30% at A10; all five characters reported. Its search does not see the RNG. The sts2ai paper measured it at 8.8% on 2,000 A10 games in the game's real engine.
3. sts2ai (HalfVulpes, arXiv 2611.12088). A10 over 12,800 games: 8.05% mean over five characters, Ironclad 15.6%. A0: 80.2%. It plays without search.
4. STS2FableBot. Real game: 20.7% at A0 over 343 runs, 19.4% at A1 over 175 runs. It uses no hidden information.
5. AttemorySystem/spire-agent. Several A20 heart wins with Ironclad and Defect; a 12-run Ironclad sample averaged floor 38.6. Whether its sts_lightspeed MCTS reads the RNG is unclear.

Also: youqing-tju/sts-agent, 3.0% at A0. zhiyue/sts2-rl-agent, about 92% combat-only wins in Act 1. alphaspire, 0.55% at A10 as measured by sts2ai.

A point worth recording: silverbot's README says the stock sts_lightspeed MCTS replays the game's real RNG stream, so it knows every future shuffle and enemy roll. Results from that search are clairvoyant. CombatSolver and SlayTheModel also see the RNG.

slaythespire.dev/projects lists more interface projects not covered by the survey: CommunicationModExtension, LudicrousSpeed, STSStateSaver, SeedSearch, and cuda-the-spire (a GPU seed sieve).

Prior-survey entries with numbers this pass found:
- SpireClimb (Epoch). GPT-6 Astra: StS1 98% at A0 and 17% at A20 heart; StS2 35% at A10. GPT-6.1 Sol: 20% at A20 heart. There were 15 attempts per character.
- sts-ironclad-agent. 50.1% heart wins over 501 runs, as summarised on slaythespire.dev. The site calls these runs in the original game; the repo's own description says the 50% is in the simulator. Check the README before using it.
